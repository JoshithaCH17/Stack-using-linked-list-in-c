# Stack Using Linked List in C

A menu-driven implementation of stack
using a singly linked list.

## Operations
- Push
- Pop
- Peek
- Display

## Concepts
- Stack (LIFO)
- Linked List
- Structures and Pointers
- Dynamic Memory Allocation

## How to Run
Compile:
gcc stack_linked_list.c -o stack_linked_list

Run on Windows:
.\stack_linked_list.exe
